# Social media and CapCut asset prompts

These prompts prioritize crop safety, motion continuity, and text-safe space so that the
generated images remain useful during video editing.

## 1. Vertical hook frame

```text
Create the opening frame for a 9:16 short video about {topic}. Show {subject} performing
{clear action} with an immediate visual question. Use a bold foreground/midground/background
separation, dynamic diagonal composition, bright focal lighting, and a simple environment.
Keep the upper 20% and lower 18% free of critical details for interface overlays. No text,
watermarks, distorted hands, or tiny clutter.
```

## 2. Three-frame transformation sequence

```text
Create three visually consistent 9:16 frames showing {subject} changing from {before state}
to {middle state} to {after state}. Lock the camera, lens, lighting direction, background,
identity, clothing, and product geometry. Change only {the intended transformation}.
Leave the center clear enough for a match cut. No captions or layout borders.
```

## 3. CapCut template cover

```text
Create a high-impact cover image for a CapCut template called {concept, not literal text}.
Feature {subject} centered with a clean silhouette, layered glow, subtle motion streaks, and
{two-color palette}. Modern creator aesthetic with strong mobile-thumbnail readability.
9:16, face and subject inside the central safe zone. Do not render words, app logos, or UI.
```

## 4. Seamless loop endpoints

```text
Design the first and last visual states for a seamless loop of {action}. The final state must
naturally align with the first in subject position, camera angle, lighting, and background.
Use a centered composition and restrained motion cues. 9:16 vertical, clean edges, no text.
Describe two frames separately while preserving every fixed visual attribute.
```

## 5. Quote-card background

```text
Create an editorial background for a social quote card about {theme}. Use {abstract material
or environment}, soft directional light, shallow layered depth, and a restrained {palette}.
Reserve a high-contrast empty rectangle covering 55% of the image for typography. 4:5 crop.
No generated words, symbols, logos, or busy texture in the text area.
```

## 6. Carousel visual system

```text
Create a coherent six-slide background system for an educational carousel about {topic}.
Each 4:5 slide uses the same grid, palette, lighting, and visual motif, while the motif evolves
from introduction to explanation to conclusion. Keep a large text-safe field and one small
illustrative focal element per slide. No text, numbers, logos, or decorative clutter.
```

## 7. Reaction cutaway image

```text
Create a humorous but believable reaction cutaway for {situation}. Show {subject} with a clear,
natural expression and one visual prop that explains the joke. Medium close-up, eye-level camera,
soft key light, clean background, mobile-readable silhouette, 9:16. Avoid exaggerated anatomy,
memes with embedded text, celebrity likenesses, or branded objects.
```

## 8. Social product reveal

```text
Create a vertical product-reveal frame where {product} is partially concealed by {material}
and revealed by a directional beam of light. Use a strong central composition, realistic
materials, controlled particles, and {brand palette}. Keep the product geometry unchanged.
9:16 with safe margins for zoom and parallax. No copy, badges, or fake interface elements.
```

## Common fixes

- Request “same seed, identity, lens, camera height, and lighting” for sequence consistency.
- Keep faces and products inside the central 60% for cross-platform cropping.
- Generate backgrounds without text; add readable typography in the editor.
- Ask for foreground layers with clean edges when planning parallax animation.

## Put the prompts into practice

The prompts are portable across compatible image tools. If you want a browser workflow for
generating frames and editing supplied reference images, you can adapt them in
[Rao Edits](https://raoedits.top/). Disclosure: Rao Edits maintains this open collection; the
examples are intentionally generator-agnostic and do not require a specific platform.
